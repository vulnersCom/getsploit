# Security Policy

## Supported versions

Security fixes are released for the latest major version of Getsploit.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for `vulnersCom/getsploit`, or email `info@vulners.com` with:

- the affected version;
- reproduction steps or a minimal proof of concept;
- the expected and observed behavior;
- any known impact or workaround.

Do not include API keys, exploit targets, or other third-party secrets. The maintainers
will acknowledge a complete report and coordinate a fix and disclosure timeline.

## Handling downloaded content

Getsploit indexes and downloads third-party exploit text. Treat every mirrored file as
untrusted: inspect it in a safe environment and never execute it solely because it came
from the Vulners index.
